# legacy

Версия 1.x на Electron и замеры Tauri. Текущая программа — в [`../wpf`](../wpf).

Этот код больше не собирается в релиз и нужен только для справки: с ним можно
сравнить, почему от него отказались.

| Что | Зачем оставили |
|---|---|
| `electron-src/` (бывший `src/`) | исходники версии 1.x |
| `electron-test/` (бывший `test/`) | её тесты |
| `electron-resources/` | ресурсы иконок |
| `tauri-spike/` | замеры памяти и размера: Tauri тянул 7 процессов и WebView2 |
| `src-tauri/` | конфигурация той пробы |
| `package.json`, `package-lock.json` | зависимости версии 1.x |

Выводы замеров, на которых стоял выбор WPF:

| | Electron 1.x | Tauri | WPF 2.x |
|---|---|---|---|
| Процессов | 4 | 7 (WebView2) | 1 |
| Память | ~225 МБ | ~200 МБ | ~90 МБ |
| Размер | 113 МБ | 3 МБ | 280 КБ |

Релизы 1.x удалены с GitHub, история коммитов осталась здесь.
